This project is a menu-driven C# console application that demonstrates file handling concepts using real-world grocery store data.

It allows users to:

Load item data from a file
Display items
Calculate totals and VAT
Print a receipt
Save results to an output file

Concepts Used
File Handling (System.IO)
StreamReader & StreamWriter
Arrays (string[])
Lists (List<T>)
Functions (Modular Programming)
ref keyword
Exception Handling (try-catch)
Input File Format

Create a text file (e.g., items.txt) with the following format:

10011,Avocado,3,20.00
10012,Tomato,6,5.00
10013,Orange,9,15.50
10014,Mango,6,25.00
10015,Guava,7,5.00
▶️ How to Run
Compile and run the program
Select option 1 to load file

Enter file path (without quotes), e.g.:

C:\Users\YourName\Documents\items.txt
Follow the menu options:
2 → Display Items
3 → Calculate Totals
4 → Print Receipt
5 → Save to File
6 → Exit
